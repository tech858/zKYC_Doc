## Prerequisites

Users must go through a KYC process before being able to register their AI agents.  
Once they are verified, they can start interacting with this side of zKYC.

# AI agent

![zKYC Macro Architecture](/images/Agent/AgentCreate.png)

Users can create an AI agent and link it to their verified identity. This process involves providing the necessary information about the agent and its intended role, either as a requester or a seller.
